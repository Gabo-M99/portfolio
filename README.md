# Gabo Moraes · Portfolio

A card-table portfolio. The page opens on a deck seen from above with "Click to Deal". Clicking deals one card per job toward the viewer; drag a card onto the table (or tap it) to open that job.

- `index.html` is the whole site: markup, styles and script in one file.
- Job content lives in the `JOBS` array inside `index.html` (`jobs.json` is a copy for reference).
- Images load from Framer's CDN (`framerusercontent.com/images/<file>`) and films from Vimeo (`player.vimeo.com/video/<id>`).

Hosted with GitHub Pages from the `main` branch.
